# Pipeline Diário

Use as ferramentas do nossocrm para fazer uma revisão completa do pipeline de vendas.

## O que fazer:

1. Busque todos os deals ativos usando as ferramentas do nossocrm
2. Agrupe por estágio (ex: Prospecção, Qualificação, Proposta, Negociação, Fechamento)
3. Identifique deals parados (sem atividade há mais de 3 dias)
4. Mostre um resumo em formato de tabela com:
   - Nome do deal
   - Estágio atual
   - Valor
   - Responsável
   - Última atividade (data)
   - Status: 🟢 Ativo | 🟡 Atenção (2-3 dias sem atividade) | 🔴 Parado (+3 dias)

5. Ao final, sugira as próximas ações para os deals em atenção ou parados.

Seja objetivo e direto. Foque nos deals que precisam de ação imediata.
