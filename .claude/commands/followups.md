# Follow-ups Pendentes

Use as ferramentas do nossocrm para listar todos os contatos e deals que precisam de retorno.

## O que fazer:

1. Busque atividades pendentes/não concluídas no nossocrm
2. Busque deals com tarefas de follow-up vencidas ou para hoje
3. Identifique contatos sem interação nos últimos 5 dias
4. Monte uma lista priorizada assim:

### 🔴 Urgente (vencido)
- Contato | Motivo | Vencimento

### 🟡 Para hoje
- Contato | Motivo | Horário

### 🔵 Esta semana
- Contato | Motivo | Data

5. Pergunte ao usuário se deseja criar uma atividade de follow-up para algum item da lista.

Foque em ações concretas — não apenas listar, mas ajudar a resolver.
